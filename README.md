# Solo Path Streetwear

Fresh rebuild of the Solo Path storefront. Plain HTML, CSS and JavaScript, no build step.

## Run it
Open `index.html` in a browser, or serve the folder with any static host (Vercel, GitHub Pages, Netlify).

## Edit the shop
- Products and prices (ZAR): `js/products.js`
- Colours and layout: `css/styles.css` (palette is at the top)
- Cart and PayFast checkout: `js/app.js`

## PayFast
The site ships with PayFast's public sandbox test details. Before going live, add your own merchant details,
set `sandbox: false` in `js/app.js`, and generate the payment signature on a server.
